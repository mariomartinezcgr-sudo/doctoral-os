# DoctoralOS V1 Scope

## Modulos visibles

- Panel.
- Capitulos.
- Lecturas.
- Plan semanal.
- Reuniones y revision.
- Escritura.
- Cuenta y sincronizacion.

## Modulos ocultos o post-v1

- Metodo avanzado.
- Corpus.
- IA etica como modulo separado.
- Defensa.
- BibTeX avanzado.
- Comunidad.
- Directores con permisos.

## Criterio de aceptacion

Un usuario nuevo debe poder:

1. Crear cuenta sin ver datos demo.
2. Crear capitulos de tesis.
3. Crear tareas semanales.
4. Registrar una reunion o comentario.
5. Registrar escritura.
6. Exportar respaldo.
