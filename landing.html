Que es DoctoralOS

Una v1 pensada para terminar, no para distraer

La app se centra en el trabajo diario de tesis: escribir, planificar, registrar feedback y mantener el progreso visible.

Capitulos

Editor con secciones, notas internas y checklist de calidad para cada capitulo.

Plan semanal

Tareas concretas con prioridad y fecha para mover la tesis cada semana.

Revision

Reuniones, acuerdos y comentarios en una sola vista para cerrar pendientes.
